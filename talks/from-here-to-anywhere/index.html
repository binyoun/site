Your first AR, in one afternoon

A photograph that opens when you look at it.

This is the same A-Frame + MindAR route I used to start. Everything runs in a phone browser and hosts for free.

  1. Choose a photograph

    High contrast and lots of detail track best. Avoid plain skies and repeating patterns.

    See example works

  2. Make the target

    Upload your image to the MindAR compiler and download the .mind file.

    MindAR image compiler

  3. Add your work

    Copy the kit, add one entry in config.json, and drop in your target and overlay (video, image or 3D model).

    Kit guide

  4. Put it online

    Turn on GitHub Pages for your copy. Your work now has a URL.

    GitHub Pages

  5. Print the label

    Use the kit’s “qr label” button, print it beside the photograph, and test on two phones.

    QR labels

Stuck on which tool to use? The AR Build Atlas compares every way to build AR: WebAR, no-code platforms, engines, tracking and hardware. Venue tip: self-host your library files, because gallery wifi often blocks CDNs.

Apply and build

What a jury needs, and the tools I use.

Build your portfolio as you go, so applying is mostly collecting what you already have.

An AR application kit

  • A live link. It runs in the browser with no app, so a juror can try it in seconds.
  • A short documentation video. Real people using the work in a real space, under two minutes.
  • Code and a citable record. Your repository on GitHub, and a DOI from a service like figshare or Zenodo.
  • The words. A short statement, a bio, and what the work needs to run (space, devices, wifi, sound).
  • Your archive. Process posts on Instagram, so you never start from zero.
